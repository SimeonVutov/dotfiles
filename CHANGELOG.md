# Changelog

## v1.0.0 - 2026-10-01

### Highlights
The desktop configuration replaces the supplied Waybar, Rofi, and wlogout interfaces with a Quickshell topbar, launcher, session menu, and monitor controls. The topbar brings together workspace, media, audio, connectivity, hardware, battery, and session features. [0, 1, 2, 3]

### Major changes
Monitor controls provide display arrangement and mode settings, including custom layouts and a timed preview that can be kept or reverted. The workspace interface replaces the numbered workspace row with an animated orbital switcher. [0, 1, 2, 3]

### Breaking changes / Migration
The supplied Waybar, Rofi launcher and monitor menus, and wlogout configuration are removed; use the corresponding Quickshell interfaces instead. The final license permits noncommercial use with attribution and requires separate written permission for commercial use; third-party material remains subject to its own terms. [1, 2, 3]

### Minor changes
Topbar modules adapt to available width, and wallpaper palette updates avoid applying stale results. Release tooling adds evidence collection and validation to the reviewed release process. [0, 1, 2, 3]
